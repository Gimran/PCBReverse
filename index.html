P — опорные точки · N — редактирование NET · K — редактирование компонентов · D — рисование
Alt+клик в режиме N — переходное отверстие (точка на обеих сторонах)

Space / Shift+Space — поворот компонента 45°
правый клик / Delete — удалить (только в режимах N / K) · Esc — выход
Images given by path are looked up in pcb_overlay_img/ next to index.html;

right-click / Delete — delete (N / K modes only) · Esc — exit mode
